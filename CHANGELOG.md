# Changelog

## 1.0.3 — 2026-10-30

- Added output format and compression-level selection based on all configured compression engines.
- Added optional 7-Zip downloads for supported Windows, macOS, and Linux architectures, with explicit consent and SHA-256 verification.
- Added support for a custom HTTPS binary URL with a required SHA-256 checksum.
- Added custom archive names and format-aware encryption options to the export dialog.
- Improved save-dialog defaults so the selected archive name and extension are preserved.
